# شکارچی بورس ایران — نسخه ۲ (اسکن کل بازار)

این پروژه یک نمونه قابل اجرا با بک‌اند است؛ برخلاف نسخه اولیه، داده‌های ساختگی ندارد و برای خواندن دیده‌بان بازار از API عمومی TSETMC تلاش می‌کند. پوشش واقعی، جریان پول حقیقی و زمان به‌روزرسانی وابسته به دسترسی و ساختار فعلی سرویس منبع است.

## امکانات
- تلاش برای دریافت فهرست کامل نمادهای بازار از MarketWatch
- پایگاه SQLite برای نگهداری عکس‌های بازار در طول روز
- اسکن زمان‌بندی‌شده در ساعت معاملاتی تهران (شنبه تا چهارشنبه، ۹ تا ۱۲:۳۰)
- صفحه‌ی جمع‌بندی مثبت/منفی، فیلتر و رتبه‌بندی نمادها، خروجی CSV
- گزارش روزانه با برترین تغییرات، ارزش معاملات و نامزدهای بررسی
- نمایش خطا و زمان آخرین دریافت موفق به‌جای جعل داده

## اجرا
نیازمندی: Python 3.10+ و دسترسی شبکه به API داده بازار.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
سپس در همان کامپیوتر مرورگر را باز کن: `http://127.0.0.1:8000`
برای دسترسی از گوشی، گوشی و کامپیوتر باید در یک شبکه باشند؛ در اجرای سرور `HOST=0.0.0.0` تنظیم کن و آدرس IP کامپیوتر را در مرورگر گوشی وارد کن. برای استفاده بیرون از شبکه و نصب PWA به میزبانی HTTPS نیاز است.

## اجرای دائمی
روی سرور لینوکس می‌توان از systemd یا یک سرویس میزبانی استفاده کرد. فرایند باید روشن بماند تا عکس‌های بازار را در طول جلسه ذخیره کند. خاموش‌بودن سرور یعنی داده‌ی جدید ثبت نمی‌شود.

## نکات فنی مهم
- داده‌های TSETMC/API عمومی ممکن است تغییر کنند، محدود شوند یا از برخی IPها در دسترس نباشند. اگر سرویس در دسترس نباشد، برنامه خطا نشان می‌دهد و ادعای «زنده» نمی‌کند.
- APIهای مورد استفاده برای بعضی فیلدها مستندات عمومی/رفتار ثابت تضمین‌شده ندارند. قبل از استفاده مالی باید تطبیق فیلدها، پوشش نمادها، واحد ریال/تومان، تأخیر و جریان حقیقی/حقوقی اعتبارسنجی شود.
- امتیاز فعلی یک غربال‌گر اولیه و شفاف است؛ هنوز بک‌تست نشده و به تنهایی سیگنال خرید یا فروش نیست.
- تعطیلات رسمی، توقف نمادها، بازارهای مختلف، صندوق‌ها، حق‌تقدم، اوراق و مشتقات ممکن است نیازمند فیلترهای جداگانه باشند.
- این پروژه به کارگزاری متصل نیست و سفارش معامله ارسال نمی‌کند.
