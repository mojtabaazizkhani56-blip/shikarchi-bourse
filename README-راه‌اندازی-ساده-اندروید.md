# راه‌اندازی شکارچی بورس روی اندروید (راهنمای ساده)

## قبل از شروع
این بسته هنوز روی اینترنت منتشر نشده است. فایل ZIP به‌تنهایی اپ نصب‌شدنی نیست؛ ابتدا باید روی سرویس میزبانی اجرا شود و سپس با Chrome به صفحه اصلی گوشی اضافه شود.

## انتشار با سرویس میزبانی
1. در GitHub یک حساب بسازید یا وارد شوید.
2. یک مخزن جدید (New repository) با نام `shikarchi-bourse` بسازید و آن را Private یا Public انتخاب کنید.
3. فایل‌های داخل این پوشه را در ریشه مخزن بارگذاری کنید؛ خود ZIP را به‌عنوان یک فایل تنها بارگذاری نکنید. باید `app.py` و `requirements.txt` و پوشه `static` و `render.yaml` در ریشه دیده شوند.
4. در Render وارد حساب شوید و از New > Blueprint یک Blueprint بسازید و مخزن GitHub را وصل کنید. تنظیمات از `render.yaml` خوانده می‌شود.
5. پس از پایان Deploy، نشانی HTTPS که Render می‌دهد را باز کنید.
6. در Chrome اندروید، منوی سه‌نقطه را باز کنید و گزینه `Add to Home screen` یا `Install app` را بزنید.

## محدودیت مهم میزبانی رایگان
طرح رایگان ممکن است سرویس را در زمان بی‌استفاده خواب کند و دیسک دائمی نداشته باشد. در این حالت پایش پیوسته و نگهداری تاریخچه تضمین نمی‌شود؛ برای پایش قابل اتکا باید سرویس همیشه‌روشن و ذخیره‌سازی پایدار داشته باشید. قبل از معامله، داده‌های دریافتی و زمان آخرین به‌روزرسانی را کنترل کنید.

## نکات داده و تحلیل
- برنامه تلاش می‌کند داده‌های عمومی بازار را از سرویس TSETMC دریافت کند؛ دسترسی یا ساختار سرویس ممکن است تغییر کند.
- تا وقتی منبع داده، پوشش نمادها، زمان تأخیر و فیلدهای حقیقی/حقوقی آزمایش نشده، کامل بودن همه نمادها و جریان پول حقیقی تضمین نیست.
- امتیازها ابزار غربالگری هستند، نه توصیه قطعی خرید یا فروش. برنامه سفارش معامله ارسال نمی‌کند.
